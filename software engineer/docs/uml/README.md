# UML Diagrams

## Use Case Diagram
- Source: `use-case-diagram.puml`
- Export: Use the VS Code PlantUML extension to export PNG/SVG.

Suggested exports:
- `use-case-diagram.png`
- `use-case-diagram.svg`

## Class Diagram
- Recommended input (best): XMI / draw.io / PlantUML / PDF export of the class diagram
- If you only have an image, export it as a high-resolution PNG or PDF so attributes/methods are readable.

Suggested placement:
- `class-diagram.png` (or `class-diagram.pdf`)
- `class-diagram-stub.puml` (names-only stub, already included)
